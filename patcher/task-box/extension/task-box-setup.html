TASK BOX — 設定

公式Clearへの直接接続を使うcompanion統合版です。この設定だけでClearやチャット削除は実行しません。

接続を確認しています。

旧拡張の無効化はこのページから検査・操作しません。確認欄は利用者による申告です。 アプリの対応版が未反映、または統合版に未完了の処理がある場合は有効化できません。 通常チャットを含むTASK BOX全体が削除対象であり、復元可能なゴミ箱ではありません。

完了済みのBOX CLEARに対して、TASK BOX Projectだけが手動削除済みである場合の復旧です。過去のClear、Project削除、Project作成は再実行しません。

この操作は、同じrequestのClear完了receiptをアプリ側でも再確認できた場合にだけ実行できます。古いreceiptは再実行防止のため保持されます。
